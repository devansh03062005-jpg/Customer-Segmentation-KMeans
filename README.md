# Customer Segmentation using K-Means Clustering
##Project Overview
This Machin learning project uses the K-Means Clustering algorithm to segment customers based on their annual income and spending score.

## Objective
TO Group customers into different segments with similar characteristics and understand their spending behavior.
##Technologies Used
- python
- Numpy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter notebook
## Dataset
The project uses the Mall Customers data set containing customer information such as:
-Customer ID
- Gender
- Age
- Annual Income
- Spending Score
  ## Methadology
  1. Data loading and exploration
  2. Data cleaning and checking
  3. Exploratory data analysis
  4. Feature selection
  5. Elbow Method
  6. K-Means clustering
  7. Customer cluster visualization
  8. Cluster analysis
     ## Files
     - Customer_Segmentation_KMeans.ipynb- Complete project notebook
     - Mall_Customers.csv- Dataset
     - Customer_Segmentation_Result.csv- Final clustering results
       ## Conclusion
       K-Means Clustering was successfully used to divide customers into groups based on their annual income and spending score. The project demonstrates the practical use of unsupervised machine learning for customer segmentation
